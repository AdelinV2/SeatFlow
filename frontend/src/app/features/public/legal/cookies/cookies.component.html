Consent decision

Decision dated 2026-09-08: NOT_REQUIRED_FOR_CURRENT_RUNTIME. Source and dependency audits found no first-party marketing cookies, no Google Analytics, GTM, PostHog, Hotjar, Clarity, pixel, or Sentry tracking, no document.cookie writes by SeatFlow, and no IndexedDB, service-worker, or cache storage introduced by SeatFlow. Each stored item below documents its strictly-necessary, requested-service rationale. The theme preference is written only after you explicitly choose a theme; the startup script only reads an existing value. This decision must be revisited before any analytics, advertising, profiling, or A/B testing SDK is added. Details and evidence live in the version-controlled inventory .ai/compliance/phase-16-privacy-storage-provider-inventory.md.

Manage storage

There are no optional categories to toggle, so this page ships no preference switches. A modal with toggles that control nothing would be dishonest and is deliberately absent. You can still:

  • sign out to remove the authentication session copy;
  • change the theme to overwrite the preference, or clear site data to remove it;
  • close the checkout tab, cancel, or let the 15-minute hold expire to drop the guest checkout proof;
  • use your browser's site-data controls to clear SeatFlow storage at any time; signing in or checking out again recreates only what that action needs.

Refusing hypothetical optional storage would never block sign-in, guest checkout, event browsing, or accessibility, because no such storage exists to refuse.

Network requests without storage

  • Google Fonts stylesheets load on every page; the fetch discloses ordinary network metadata but sets no SeatFlow-managed storage.
  • Nominatim geocoding is called directly from the browser on venue pages and discloses the typed address or coordinates to that endpoint; it sets no SeatFlow-managed storage.
  • AI provider (only where enabled): prompts are processed server-side by the configured provider with no persistent SeatFlow browser chat storage; provider retention follows that provider's terms.

When this changes

If SeatFlow adds analytics, advertising, profiling, or any other optional storage, this page and the inventory will name it, its provider, purpose, and lifetime before it ships, and a real consent layer that blocks it until you agree (and honors refusal and withdrawal) will ship with it. Until then, the absence of a banner is the honest state. Related detail: privacy notice, terms, security.
